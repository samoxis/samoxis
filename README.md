# Sorin (@samoxis)

Builder focused on robotics autonomy, agent tool protocols (MCP), and local hardware telemetry.

---

### 🦆 Embodied AI & Robotics
* **[microduck-brain](https://github.com/samoxis/microduck-brain)** — Zero-dependency Python autonomy layer for Hugging Face's Microduck biped robot. Handles heading stabilization, drop avoidance, and dynamic obstacle steering over JSON-RPC in MuJoCo simulation.
* **[microduck_rl](https://github.com/samoxis/microduck_rl)** — Reinforcement learning environments and gait experimentation for biped locomotion.

### 🔌 Agent Protocols & Infrastructure
* **[mcp-youtube-stack](https://github.com/samoxis/mcp-youtube-stack)** — Production-grade Model Context Protocol (FastMCP) servers behind Cloudflare Tunnels with OAuth authentication. Connects LLM clients (Claude, Cursor) directly to search and transcript engines.

### 🖥️ Systems & Visualization
* **[desktop-weather](https://github.com/samoxis/desktop-weather)** — Generative 2.5D visual sensor screen that reflects live CPU, GPU, memory, and disk telemetry through an animated countryside.  
  👉 **[Live Interactive Demo](https://samoxis.github.io/desktop-weather/?demo=idle)**
